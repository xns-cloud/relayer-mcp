# Contributing to @xns-cloud/relayer-mcp

## Development happens on GitLab

This GitHub repository is a **read-only mirror** of the canonical source at
[gitlab.com/scpcorp/relayer-mcp](https://gitlab.com/scpcorp/relayer-mcp).
All development — issues, merge requests, CI, and releases — happens there.

## How to contribute

1. **Report a bug or request a feature:**
   Open an issue on [GitLab](https://gitlab.com/scpcorp/relayer-mcp/-/issues).

2. **Submit a code change:**
   Fork the [GitLab repo](https://gitlab.com/scpcorp/relayer-mcp), make your changes,
   and open a merge request there.

3. **Pull requests opened on GitHub will not be merged.**
   The mirror syncs automatically from GitLab; changes made on GitHub would be
   overwritten on the next sync. We will point you to GitLab if you open a PR here.

## Local development

```bash
npm install
npm test
```

Requires Node.js 20+.
